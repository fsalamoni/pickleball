# `marketplace/components/` — componentes do módulo (PLANEJADO)

A UI das telas V2 mora em `src/v2/components/marketplace/` (lista completa
em `docs/FUTURO/MERCADO/06-UX-ROTAS-E-TELAS.md` §4).

Aqui ficam apenas componentes **acoplados ao domínio do módulo** e
reutilizados fora das páginas V2 — por exemplo:

| Componente | Onde é usado fora do Mercado |
|---|---|
| `SellListingButton.jsx` | PDV da arena, perfil do professor |
| `ListingMiniCard.jsx` | Feed (post `listing`), busca global, perfil |
| `SellerTrustBadge.jsx` | perfil do atleta, página da arena |
