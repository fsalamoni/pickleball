# `feed/components/` — componentes do módulo (PLANEJADO)

A UI das telas V2 mora em `src/v2/components/feed/` (28 componentes
listados em `docs/FUTURO/FEED/06-UX-ROTAS-E-TELAS.md` §4).

Aqui ficam os componentes reutilizados **fora** do feed:

| Componente | Onde é usado |
|---|---|
| `ShareToFeedButton.jsx` | anúncio do Mercado, torneio, conquista, dia de jogo |
| `FeedPostMiniCard.jsx` | Home, perfil, busca global |
| `FollowEntityButton.jsx` | página da arena, do clube, do professor |
| `AuthorIdentityPicker.jsx` | qualquer tela que publique em nome de entidade |
